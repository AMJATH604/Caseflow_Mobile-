1. The Core Problem

"If we ask money to advocates they won't pay for a monthly subscription."

This is 100% accurate for the Indian legal market. Here's why:

FactorReality
Price sensitivityMost Indian advocates (district/taluk courts) earn ₹15K–₹50K/month
Tech adoptionLow trust in digital tools — "my diary system works fine"
Subscription fatigueThey already pay for phone, internet, bar council fees
CompetitionMany free alternatives (eCourts, WhatsApp groups)
Payment habitPrefer one-time payments over recurring SaaS
🎯 The Golden Rule: Never charge advocates for things they can do on paper. Charge them for things they cannot do without your app.

2. Strategy: "Free Core, Paid Power"

Make CaseFlow indispensable for free, then monetize the superpowers.

Think of it like:

  • WhatsApp — free messaging, WhatsApp Business charges for automation
  • Google Maps — free navigation, businesses pay for placement
  • Canva — free design, premium templates cost money
✅ Free: Daily essentials (calendar, hearings, calculators, bare acts)
💰 Paid: Power tools (AI, PDF tools, unlimited cases, collaboration)

4. Revenue Stream 2 — Transaction-Based Revenue

Advocates won't pay for an app, but they already pay for services. CaseFlow becomes the gateway.

4A. eCourts ePay Commission

WhatHow
Court fee paymentsPartner with Razorpay/PayU — earn 0.5-1% per transaction
Stamp paper purchaseDigital stamps via StampReady/SHCIL — earn ₹5-20/txn
E-filing feesRoute eFiling payments through CaseFlow
Example: 1,000 advocates × ₹500 avg × 4 txn/month = ₹20L volume → ₹20,000/month at 1%

4B. Certified Copy Ordering

  • Advocates NEED certified copies — currently go physically or use agents (₹200-500)
  • CaseFlow facilitates digitally via agent network per district
  • Revenue: ₹50-100 per copy facilitated

4C. Process Service / Summon Tracking

  • Partner with registered process servers
  • Book service through the app
  • Revenue: ₹100-200 commission per service

10. Implementation Roadmap

Phase 1: Foundation (Month 1-2) — Start Earning

  • Implement tiered plan system in Supabase (user_plans table)
  • Add soft paywalls (case limit, AI query limit)
  • Integrate Razorpay for Indian payments (UPI, cards, netbanking)
  • Launch at ₹999/year introductory price (₹499 for beta users)
  • Add "Upgrade" prompts at natural friction points

Phase 2: Transaction Revenue (Month 3-4)

  • Partner with payment gateway for ePay court fees
  • Build certified copy ordering workflow
  • Add non-intrusive banner ads for free users
  • Launch referral program: "Refer a colleague, get 1 month Pro free"

Phase 3: B2B Pipeline (Month 5-6)

  • Approach 3-5 Bar Associations for pilot
  • Build white-label capability
  • Create enterprise admin dashboard
  • Launch law college partnership program

Phase 4: Scale (Month 7-12)

  • AI usage-based billing
  • API marketplace launch
  • Data insights products
  • State government DLSA proposals

12. Technical Architecture

Database Schema (Supabase)

-- User subscription tracking
CREATE TABLE user_plans (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES auth.users(id),
  plan_type TEXT DEFAULT 'free',
  billing_cycle TEXT,
  expires_at TIMESTAMPTZ,
  razorpay_subscription_id TEXT,
  is_active BOOLEAN DEFAULT true,
  created_at TIMESTAMPTZ DEFAULT now()
);

-- Usage metering
CREATE TABLE usage_tracking (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES auth.users(id),
  feature TEXT NOT NULL,
  used_at TIMESTAMPTZ DEFAULT now()
);

-- Billing transactions
CREATE TABLE billing_transactions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES auth.users(id),
  amount DECIMAL(10,2) NOT NULL,
  type TEXT,
  status TEXT DEFAULT 'pending',
  razorpay_payment_id TEXT,
  created_at TIMESTAMPTZ DEFAULT now()
);

13. Quick Wins — Start Today

  1. Case limit (25 free) — Add check in CaseRepository.createCase(). Show upgrade screen when limit hit.
  2. AI query counter — Already tracked in ai_chat_history. Add daily count in GeminiService.
  3. PDF tools lock — Tools already have "plan": "pro" tags! Just enforce it.
  4. "Pro" badge in Advocate Directory — Pro users get highlighted listing.
  5. Ads for free users — Add banner ads to dashboard. Pro = clean, ad-free.
