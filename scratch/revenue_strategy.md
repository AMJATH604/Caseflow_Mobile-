# 1. The Core Problem

> "If we ask money to advocates they won't pay for a monthly subscription."

This is **100% accurate** for the Indian legal market. Here's why:

| Factor | Reality |
|--------|---------|
| **Price sensitivity** | Most Indian advocates (especially district/taluk courts) earn ₹15K–₹50K/month |
| **Tech adoption** | Low trust in digital tools — "my diary system works fine" |
| **Subscription fatigue** | They already pay for phone, internet, bar council fees |
| **Competition** | Many free alternatives (eCourts, WhatsApp groups) |
| **Payment habit** | Prefer one-time payments over recurring SaaS |

> **The Golden Rule:** Never charge advocates for things they can do on paper. Charge them for things they **cannot do without your app**.

<div style="page-break-after: always;"></div>

# 2. Strategy: "Free Core, Paid Power"

The idea is simple: **Make CaseFlow indispensable for free, then monetize the superpowers.**

Think of it like:
- **WhatsApp** — free messaging, but WhatsApp Business charges for automation
- **Google Maps** — free navigation, but businesses pay for placement
- **Canva** — free design, but premium templates cost money

CaseFlow should follow the same pattern:
- **Free:** Daily essentials (calendar, hearings, calculators, bare acts)
- **Paid:** Power tools (AI, PDF tools, unlimited cases, collaboration)

<div style="page-break-after: always;"></div>

- Lifetime option at ₹2,499 for early adopters

# 4. Revenue Stream 2 — Transaction-Based Revenue

This is where the **real revenue** lies. Advocates won't pay for an app, but they **already pay** for services.

### 4A. eCourts ePay Commission

| What | How |
|------|-----|
| Court fee payments | Partner with Razorpay/PayU — earn 0.5-1% per transaction |
| Stamp paper purchase | Digital stamps via StampReady/SHCIL — earn ₹5-20/txn |
| E-filing fees | Route eFiling payments through CaseFlow |

> **Example:** 1,000 advocates × ₹500 avg × 4 transactions/month = ₹20,00,000 volume → **₹20,000/month at 1% commission**

### 4B. Certified Copy Ordering Service

- Advocates NEED certified copies from courts
- Current process: physically visit or use agents (₹200-500)
- CaseFlow can facilitate digitally via agent network
- **Revenue:** ₹50-100 per copy facilitated

### 4C. Process Service / Summon Tracking

- Partner with registered process servers
- Advocates book service through the app
- **Revenue:** ₹100-200 commission per service

> **Estimate:** 5,000 DAU × ₹2 eCPM = ₹10,000/day = **₹3,00,000/month**

# 12. Technical Architecture

### Database Schema (Supabase)

```sql
-- User subscription tracking
CREATE TABLE user_plans (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES auth.users(id),
  plan_type TEXT DEFAULT 'free',
  billing_cycle TEXT,
  expires_at TIMESTAMPTZ,
  razorpay_subscription_id TEXT,
  is_active BOOLEAN DEFAULT true,
  created_at TIMESTAMPTZ DEFAULT now()
);

-- Usage metering
CREATE TABLE usage_tracking (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES auth.users(id),
  feature TEXT NOT NULL,
  used_at TIMESTAMPTZ DEFAULT now()
);

-- Billing transactions
CREATE TABLE billing_transactions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES auth.users(id),
  amount DECIMAL(10,2) NOT NULL,
  type TEXT,
  status TEXT DEFAULT 'pending',
  razorpay_payment_id TEXT,
  created_at TIMESTAMPTZ DEFAULT now()
);
```

# 13. Quick Wins — Start Today

These require **minimal code changes** but immediately create upgrade incentives:

1. **Case limit (25 free)** — Add check in `CaseRepository.createCase()`. Show upgrade screen when limit hit.

2. **AI query counter** — Already tracked in `ai_chat_history`. Add daily count check in `GeminiService.sendMessage()`.

3. **PDF tools lock** — Tools already have `"plan": "pro"` tags! Just enforce it.

4. **"Pro" badge in Advocate Directory** — Pro users get highlighted listing.

5. **Remove ads for Pro** — Add banner ads to dashboard for free users. Pro = clean dashboard.
